# Погода

Приложение показывает текущую погоду, почасовой прогноз на сутки и прогноз на 7 дней. Города можно искать на русском языке; кнопка с геометкой показывает погоду по текущему местоположению.

Прогноз и поиск городов предоставляются сервисом [Open-Meteo](https://open-meteo.com/) и не требуют API-ключа. Геолокация доступна после разрешения пользователя; для браузера требуется защищённое соединение (HTTPS) или `localhost`.

### Запуск в GitHub Codespaces

Из каталога `weather` выполните:

```sh
flutter pub get
python3 preview_server.py
```

Скрипт собирает веб-приложение и запускает его на порту `3000`. В Codespaces откройте порт `3000` во вкладке **Ports**. Сервер проксирует запросы прогноза и поиска к Open-Meteo: это помогает, если браузер Codespaces не может обратиться к внешнему API напрямую.

После изменения кода остановите сервер (`Ctrl+C`) и запустите `python3 preview_server.py` снова, чтобы пересобрать приложение.

### Локальный запуск

```sh
flutter pub get
flutter run
```
